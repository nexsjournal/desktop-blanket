# 桌面毛毯 - 打包成应用完整指南

## 🎯 你现在需要做的

### 第一步：运行构建命令

```bash
cd /Users/lex/Code/ProjStudy/desktop-blanket
./build_app.sh
```

**这个脚本会自动**：
1. 安装打包工具 py2app
2. 清理旧文件
3. 打包成 `Desktop Rug.app`

**预计时间**：首次构建约 2-3 分钟（需要安装 py2app）

---

### 第二步：使用你的应用

构建成功后，你会看到：

```
✅ 构建成功！
📍 应用位置: /Users/lex/Code/ProjStudy/desktop-blanket/dist/rug.app
```

**现在有两个选择**：

#### 选择 A：移动到应用程序文件夹（推荐）

```bash
mv dist/rug.app /Applications/
```

然后你就可以：
- 在启动台找到 "rug" 应用
- 在应用程序文件夹双击运行
- 像其他 Mac 应用一样使用

#### 选择 B：直接运行

```bash
open dist/rug.app
```

---

### 第三步：首次运行设置

**如果出现"无法打开"警告**（因为没签名）：

1. 打开"访达"，找到应用
2. **右键点击应用** → 选择"打开"
3. 在弹出对话框点"打开"

**如果要求授权**：
- 系统设置 → 隐私与安全性 → 自动化
- 允许访问 Finder（用于读取图标位置）

**之后就可以正常双击运行了**！

## ⚠️ 可能遇到的问题

### 问题 1：构建失败

**解决**：
```bash
source .venv/bin/activate
pip install --upgrade py2app setuptools wheel
./build_app.sh
```

### 问题 2：应用打不开

**解决**：
```bash
# 查看详细错误
dist/rug.app/Contents/MacOS/rug
```

然后把错误信息告诉我。

### 问题 3：缺少文件

确保这些文件存在：
```bash
ls assets/rugs/rug-01.png
ls assets/rugs/rug-01-back.png
```

## 🎨 自定义应用图标（可选）

如果你想要自定义图标：

1. 准备一个 `.icns` 格式的图标文件
2. 放在项目根目录，命名为 `icon.icns`
3. 编辑 `setup.py`，找到第 18 行：
   ```python
   'iconfile': None,
   ```
   改成：
   ```python
   'iconfile': 'icon.icns',
   ```
4. 重新运行 `./build_app.sh`
