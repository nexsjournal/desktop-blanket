## 🎯 如何使用

### 应用已经启动了！

查看你的菜单栏（屏幕右上角），应该能看到 **Rug** 图标。

**点击图标**可以：
- 铺上（⌘\\）
- 掀开
- 切换款式
- 设置
- 退出

### 如果没看到菜单栏图标

1. 打开"访达" → "应用程序"
2. 找到"桌面毛毯"（带红色图标）
3. **右键点击** → 选择"打开"（首次需要这样）
4. 点"打开"确认

---

## 🚀 后续使用

以后启动应用有多种方式：

### 方式1：启动台
- 打开启动台
- 找到"桌面毛毯"（红色毛毯图标）
- 点击启动

### 方式2：Spotlight
- 按 `Cmd + Space`
- 输入"桌面毛毯"或"rug"

### 方式3：应用程序文件夹
- 访达 → 应用程序
- 双击"桌面毛毯"

## ⚙️ 设置开机自启（推荐）

这样每次开机就自动有毛毯了：

1. **系统设置** → **通用** → **登录项**
2. 点击 **"+"** 按钮
3. 选择 **"桌面毛毯"**
4. 确认

## 🔧 如果遇到问题

### 应用无法打开
- 右键点击应用 → 打开（不要直接双击）

### 菜单栏没有图标
- 应用可能启动失败，查看：
  ```bash
  /Applications/桌面毛毯.app/Contents/MacOS/launcher
  ```
  
### 需要权限
- 系统设置 → 隐私与安全性 → 自动化
- 允许"桌面毛毯"访问 Finder
