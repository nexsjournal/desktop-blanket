## 🚀 现在你可以

### 1. 启动应用

**方式一：启动台**
- 打开启动台（Launchpad）
- 搜索 "Desktop Rug"
- 点击图标启动

**方式二：应用程序文件夹**
- 打开访达 → 应用程序
- 找到 "Desktop Rug"
- 双击启动

**方式三：Spotlight**
- 按 `Cmd + Space`
- 输入 "Desktop Rug"
- 回车启动

---

## ⚠️ 首次启动

因为应用没有签名，第一次运行时：

### 如果出现"无法打开"警告

1. 打开"访达" → "应用程序"
2. 找到 "Desktop Rug"
3. **按住 Control 键点击**（或右键点击）
4. 选择"打开"
5. 在弹出对话框中点"打开"

**之后就可以正常双击启动了！**

### 授予权限

如果弹出权限请求：
- 允许"自动化"权限（读取Finder图标位置）
- 系统设置 → 隐私与安全性 → 自动化 → 确认

---

## 🎯 使用应用

启动后：
- 菜单栏出现 Rug 图标
- 点击图标 → "铺上"
- 就能看到毛毯了！

**完全不需要再打开终端或命令行！**

## 🔄 设置开机自启（可选）

想要每次开机自动启动？

1. 系统设置 → 通用 → 登录项
2. 点击 "+" 按钮
3. 选择 `/Applications/Desktop Rug.app`
4. 确认
