# 如何打包成 macOS 应用

## 简单步骤

### 1. 运行构建脚本

```bash
cd /Users/lex/Code/ProjStudy/desktop-blanket
./build_app.sh
```

这个脚本会：
- 自动安装 py2app（如果还没有）
- 清理旧的构建文件
- 打包成 `Desktop Rug.app`

### 2. 使用应用

构建完成后，你会在 `dist/` 文件夹看到 `rug.app`

**方式一：移动到应用程序文件夹**
```bash
mv dist/rug.app /Applications/
```
然后在启动台或应用程序文件夹里找到并双击运行

**方式二：直接运行**
```bash
open dist/rug.app
```

### 3. 首次运行

由于应用没有签名，首次运行时：

1. **如果出现"无法打开"的警告**：
   - 右键点击应用 → 选择"打开"
   - 在弹出的对话框中点"打开"

2. **授予权限**（如果弹出）：
   - 自动化权限：允许访问Finder（读取图标位置）
   - 在系统设置 → 隐私与安全性 → 自动化 中确认

### 4. 后续使用

一旦完成首次设置，之后就可以：
- 双击应用图标启动
- 添加到"登录项"实现开机自启
- 完全像普通 macOS 应用一样使用

---

## 添加到登录项（开机自启）

1. 打开"系统设置"
2. 进入"通用" → "登录项"
3. 点击"+"添加 `Desktop Rug.app`
4. 确认添加

这样每次开机就会自动启动了。

---

## 高级选项

### 自定义应用图标

如果你有图标文件（.icns 格式）：

1. 准备图标文件 `icon.icns`
2. 编辑 `setup.py`，找到：
   ```python
   'iconfile': None,
   ```
   改成：
   ```python
   'iconfile': 'icon.icns',
   ```
3. 重新运行 `./build_app.sh`

### 重新构建

如果修改了代码需要重新打包：
```bash
./build_app.sh
```

它会自动清理旧版本并重新构建。

## 故障排除

### 问题：构建失败

**解决**：
```bash
source .venv/bin/activate
pip install --upgrade py2app setuptools
./build_app.sh
```

### 问题：应用无法运行

**解决**：
1. 检查终端输出的错误信息
2. 尝试从终端运行查看详细错误：
   ```bash
   dist/rug.app/Contents/MacOS/rug
   ```

### 问题：找不到贴图文件

**解决**：确保 `assets/rugs/` 文件夹存在且包含：
- `rug-01.png`
- `rug-01-back.png`

## 文件说明

- `setup.py` - py2app 打包配置
- `build_app.sh` - 自动化构建脚本
- `dist/rug.app` - 构建出的应用（构建后生成）
- `build/` - 临时构建文件（可以删除）
