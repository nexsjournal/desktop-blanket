# 桌面毛毯（Desktop Rug）——素材说明

把你找到的地毯/毛毯图片放进这个文件夹即可，命名建议 `rug-01.png`、`rug-02.png`……

## 规格要求（尽量满足，不满足也没关系，我来处理）

| 项目 | 要求 |
| --- | --- |
| 视角 | **正俯视**（从毯子正上方拍摄/扫描，不要斜视角） |
| 光照 | 越均匀越好，**不要有强烈的投影和反光**（阴影由程序实时画） |
| 边缘 | 图片边缘 = 毯子物理边缘，方角或圆角都行；毯子以外的区域最好是透明的（PNG alpha 通道） |
| 比例 | 建议横向长方形，长宽比约 1 : 0.6 ~ 0.7（接近参考视频里的波斯地毯） |
| 分辨率 | 宽度 ≥ 2048px 最佳（低于也可以，会稍微糊一点） |
| 格式 | PNG / JPG / WEBP 都可以 |

## 交付后我来做的事

抠图（如果带背景）、裁剪、缩放到引擎贴图规格、生成预览。你只需要把图丢进来，然后告诉我一声「素材放好了」。
